AIエージェントくらべ帳

Muse・dots・Grok Bot・Claude Duet ― 話題のAIエージェント4つのちがいをざっくり把握（2026年11月1日時点）

💡 AIエージェントとは、質問に答えるだけでなく、メールや予約、資料づくりなどの作業を任せっぱなしで進めてくれるAIのこと。2026年の秋、大手各社から一気に登場しました。ここでは個人で使える4つを比べます。
🌸
Muse
Meta（Facebook・Instagramの会社）
🇯🇵 日本で使える
暮らしの用事を片づける、個人の秘書
メール・予定・旅行の予約・買い物など、生活の「やっておいて」を任せる。無料で始められて、日本でも10月23日から提供開始。
無料ありスマホ中心Instagram連携買う前に確認
⚪
dots
OpenAI（ChatGPTの会社）
🇯🇵 日本で使える（Proプラン）
仕事を丸ごと任せる、有能な相棒1人
1体の「dot」が、会話を閉じたあとも裏で作業を続ける。4,000以上のアプリとつながり、Slack・Teamsからも指示できる。月100ドル〜のChatGPT Proが必要。
無料なし仕事向けSlack/TeamsGPT-6 Astra
🤖
Grok Bot
xAI（Grokの会社。Cursor経由の提供も）
🇯🇵 公式には未対応（使えた報告あり）
役割別のBotを何体も持てる、AIチーム
「調べる係」「まとめる係」など名前つきのBotを複数作り、決まった時間に動かせる。X（旧Twitter）の公開投稿の収集が得意。月20〜30ドルのプランで使える（まだベータ）。
お試しあり複数BotX検索PCアプリ
🧡
Claude Duet
Anthropic（Claudeの会社）
🇯🇵 日本ではまだ使えません
先回りして知らせてくれる、仕事の参謀
毎朝メールと予定の大事なところをまとめて報告し、アプリを閉じても裏で作業を続ける。送信・支払い・署名・削除の前には必ず確認。ClaudeのProプラン（月20ドル）に追加料金なしで含まれるが、今はアメリカのPro・Max会員だけが順番待ちで申し込める研究プレビュー。
米国のみ仕事向け毎朝のまとめClaude Opus 5.5

※Claude Duetは日本では未提供（2026年11月1日時点）。
※料金はドル表記が基本。日本円は報道ベースの参考値。Grok Botの入口プランは記事により「SuperGrok」「X Premium」「Cursor Pro」と書き方が分かれています。

同じお願い：「来週の出張、新幹線とホテルを取って、関係者にメールしといて」

🌸
Muse の場合

LINEみたいにメッセージを送ると、カレンダーを見て候補を出し、予約サイトで手配。支払いやメール送信の直前に「これでいい？」と聞いてくる。パスワードやカード番号はAIから見えない作り。

→ 気の利く執事。家族旅行・買い物・返品など「生活」の用事が一番得意。

⚪
dots の場合

1体のdotが計画を立て、裏で手分けして作業。ChatGPTを閉じても続けてくれて、終わったらSlackやChatGPTに報告。仕事の資料作りやコード修正まで同じ相棒に頼める。

→ できる部下1人に全部任せる感じ。ただし月額が高く、スマホからはdotを新規作成できない。

🤖
Grok Bot の場合

「出張手配Bot」「連絡Bot」を別々に作って役割分担。Bot同士は同じクラウドPCを共有していて、ファイルやログインを受け渡せる。毎週の定例作業として登録も可能。

→ 班長がチームに仕事を振る感じ。仕組みは分かりやすいが、まだベータでBotが存在しない機能を言うことも。

🧡
Claude Duet の場合
🇯🇵 日本ではまだ使えません（アメリカのみ）

頼む前に、朝のまとめで「来週の出張、まだ新幹線取ってないよ」と先に教えてくれるタイプ。手配やメールの下書きを進めて、送る・払う前に確認。パスワードはAIに見えず、支払いは1回限りのカード番号。

→ 先回りする参謀。ただしチケット予約など個人の用事はまだ苦手で、チェックも数時間おき。
